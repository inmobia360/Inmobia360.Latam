# Roadmap

Fecha de aprobación del marco: 2026-08-27.

## Fase 1 — Base de conocimiento y gobierno

- Estado: aprobada y en ejecución documental.
- Crear y mantener los nueve archivos de gobierno definidos para esta fase.
- Consolidar identidad, alcance, arquitectura aprobada, objetivos, riesgos y decisiones.
- No programar, instalar dependencias ni construir skills.

## Fase 1B — Sistema director de skills

- Estado: completada documentalmente; validación de comportamiento pendiente.
- Construir `latam-real-estate` versión `0.1.0`.
- Definir perfiles de especialistas, derechos de decisión, puertas de calidad y formato de informe.
- Crear registro de skills y control de skills externas.
- Mantener las skills especialistas en estado `planned`.

## Fase 2 — Definición validable del MVP Perú

- Estado: pendiente de aprobación.
- Detallar usuarios, flujos, criterios de éxito, métricas y exclusiones.
- Mantener Lima como piloto y WhatsApp como canal prioritario.
- Trabajar sin datos personales reales.

## Fase 3 — Diseño y construcción técnica

- Estado: pendiente de aprobación.
- Diseñar la aplicación Next.js, las webs WordPress + Bricks y los contratos de integración.
- Definir modelo de datos, seguridad, pruebas y control de releases.

## Fase 4 — Validación piloto

- Estado: pendiente de aprobación.
- Validar el MVP en Lima con datos controlados y criterios de éxito aprobados.

## Expansión regional

Fuera del alcance inicial. No se iniciará hasta que exista una decisión aprobada.

Las fechas, responsables, dependencias y criterios de salida de las fases pendientes son hipótesis y requieren validación.
