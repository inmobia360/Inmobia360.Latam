# Criterios de selección del modelo y proveedor de IA

Estado: marco de evaluación. No selecciona ni conecta ningún proveedor.

## Criterios obligatorios

| Criterio | Pregunta de evaluación |
|---|---|
| Seguridad | ¿Qué controles existen para credenciales, aislamiento, abuso y registro? |
| Privacidad | ¿Cómo se almacenan, retienen y utilizan los datos enviados? |
| Jurisdicción | ¿Dónde se procesan los datos y qué condiciones aplican? |
| Fiabilidad | ¿Qué disponibilidad, límites y mecanismos de reintento ofrece? |
| Coste | ¿Cómo se mide el consumo y qué límites preventivos pueden configurarse? |
| Capacidad | ¿Responde adecuadamente a las tareas reales del MVP? |
| Portabilidad | ¿Existe una ruta razonable para cambiar de proveedor o modelo? |
| Operación | ¿Puede supervisarse, auditarse y detenerse desde el VPS? |

## Reglas

- La popularidad no se considerará prueba suficiente de seguridad.
- No se enviarán datos personales reales durante la evaluación.
- No se aprobará un proveedor sin revisar sus condiciones y controles vigentes.
- La selección requerirá una comparación documentada y aprobación de Juan.
- La primera integración deberá ser reversible y limitada a tareas no destructivas.

## Información pendiente

- Proveedor o proveedores candidatos.
- Casos de uso prioritarios.
- Volumen estimado de tareas.
- Presupuesto aprobado.
- Requisitos de residencia y retención de datos.
