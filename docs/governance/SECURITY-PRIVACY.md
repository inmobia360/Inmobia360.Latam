# Seguridad y privacidad

Este documento registra directrices, no una implementación.

- No almacenar credenciales, tokens, datos de producción ni información personal innecesaria.
- Tratar leads, contactos, direcciones exactas y documentos inmobiliarios como datos potencialmente sensibles.
- Definir consentimiento, finalidad, retención, acceso, auditoría y eliminación antes de operar con datos reales.
- Separar datos observados, contractuales, estimados y recomendaciones.
- Revisar términos de uso, privacidad, atribución y retención de cualquier fuente externa.
- Diseñar validación de backend, control de acceso, consultas preparadas, cabeceras seguras, limitación de tasa, errores seguros y trazabilidad cuando se implemente.

Los requisitos jurídicos concretos para Perú y otros países están pendientes de revisión especializada.
