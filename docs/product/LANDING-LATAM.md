# Landing LATAM

Documento reservado para la propuesta y copy de la landing regional.

## Arquitectura de publicación

- Landing institucional LATAM: `inmobia360.com`.
- Landing comercial inicial: `inmobia360.com/pe/`.
- Futuras landings regionales: `/co/`, `/mx/` y `/cl/`, sujetas a validación y publicación posterior.
- Aplicación SaaS y demo: subdominios separados.

La landing debe presentar a Inmobia360 LATAM como una plataforma PropTech para que agentes y pequeñas agencias creen presencia, publiquen propiedades, gestionen oportunidades y colaboren con confianza. El tono será profesional, claro, cercano y verificable; no se presentará como portal masivo ni prometerá resultados garantizados.

## Arquitectura de propuesta

- Entrada por rol: agente, agencia, captador, colaborador o partner.
- Beneficio inicial: publicar una propiedad y obtener una página profesional.
- Beneficio operativo: leads, asistente, contenidos y seguimiento.
- Evolución: Red Profesional, reputación y acompañamiento.
- CTA principal candidato: crear perfil o probar la experiencia con datos sintéticos.
