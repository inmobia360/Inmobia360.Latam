# Documentación del proyecto

## Ubicación

- Gobierno: `docs/governance/`.
- Producto: `docs/product/`.
- Países: `docs/countries/`.
- Skills propias: `.agents/skills/`.
- Registro de skills y proveedores: `.codex/`.

## Reglas de actualización

- No duplicar hechos cambiantes dentro de `SKILL.md`.
- Registrar decisiones con fecha, responsable, motivo, evidencia y estado.
- Registrar riesgos con impacto, probabilidad, mitigación y propietario cuando estén disponibles.
- Mantener adaptaciones por país separadas de la documentación LATAM.
- Marcar explícitamente la información pendiente de validación.
