# Puertas de calidad

| Transición | Condición mínima | Evidencia |
|---|---|---|
| Idea → investigación | Problema y usuario identificados | Brief aprobado |
| Investigación → prototipo | Evidencia suficiente del problema | Hallazgos trazables |
| Prototipo → desarrollo | Flujo probado y alcance definido | Criterios de aceptación |
| Desarrollo → piloto | Seguridad, pruebas y datos controlados | Informe QA |
| Piloto → comercialización | Uso recurrente y disposición de pago | Resultados verificables |
| Perú → otro país | Proceso repetible y decisión aprobada | Evaluación de expansión |
| Staging → producción | Pruebas, backup, rollback y aprobación de Juan | Checklist firmado |

## Resultado

- `GO`: condiciones satisfechas.
- `GO CONDICIONADO`: faltan acciones concretas con riesgo aceptado.
- `NO-GO`: condición crítica incumplida.
- `INFORMACIÓN INSUFICIENTE`: no hay evidencia suficiente para decidir.
