# Flujo ejecutivo

## Intake

Registrar objetivo, solicitante, usuario afectado, país, fase, restricciones, entregables y si existen efectos externos.

## Diagnóstico

Consultar documentación vigente. Etiquetar cada dato como `HECHO`, `HIPÓTESIS`, `ESTIMACIÓN`, `RECOMENDACIÓN` o `DECISIÓN`.

## Plan

Definir tareas, dependencias, riesgos, criterios de aceptación y puerta de calidad. No avanzar automáticamente a la siguiente fase.

## Delegación

Seleccionar los perfiles mínimos necesarios. Cada perfil debe recibir contexto, pregunta, límites, evidencia disponible y formato de salida.

## Síntesis

Comparar resultados, hacer explícitas las discrepancias y no ocultar incertidumbre. Si dos resultados son incompatibles, detenerse y elevar la decisión.

## Aprobación

Requerir aprobación de Juan para cambios de alcance, presupuesto, precios, entrada a países, contratos, compras, datos sensibles, contacto externo, permisos, producción o acciones irreversibles.

## Cierre

Verificar criterios de aceptación, registrar evidencia, actualizar documentos autorizados y entregar el informe ejecutivo.
